# Core Entities
1. Rider
    - user who requests rides on the platform 
2. Driver
    - user who registers as a driver for the platform and provide transportation services 
3. Fare
    - represents the estimated cost for a ride. includes pickup and destination location, estimated time of arrival.
4. Ride
    - represents the entire lifecycle of a ride until completion
    - which includes rider requesting a ride, estimated fare, details of rider, driver, timestamps for pickup and dropoff, actual fare charged.
5. Location
    - represents real time location of drivers which includes a latitude and longitude coordinates, timestamp of last update
